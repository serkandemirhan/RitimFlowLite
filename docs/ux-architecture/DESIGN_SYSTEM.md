# Ortak arayüz

Mevcut premium tipografi, lacivert/ beyaz/mavi renkler, `.card`, `.btn`, `.input`, `.select` ve mevcut diyalog odak yönetimi kullanılır. Ana alanlar masaüstü kenar çubuğu ve mobil gezinmede, alt işlemler bağlamsal ikinci gezinmede gösterilir. Depoda görev panelleri yalnız seçilen görevi açar. Form, doğrulama, bilinmeyen işlem ve hata durumları mevcut sunucu/kurtarma akışlarını kullanır.

320–1440 CSS piksel tarayıcı kanıtları gerçek mobil cihaz kabulü değildir. Bütün alanlarda son görsel ve erişilebilirlik incelemesi henüz tamamlanmadı.
