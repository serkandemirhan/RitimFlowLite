# Demo v1.0 — bağımsız veri alanı

28 Ekim 2026. Strateji kurgusal verili demo; eski verileri içe aktarma veya production kullanımı değildir. **NO-GO:** GitHub Actions, yayın ortamı, gerçek mobil kabulü ve sabit candidate incelemesi tamamlanmadı. Adayın Pages deploy işi kapalıdır; mevcut canlı siteye dokunulmadı ve push/deploy yapılmadı.

Etkin yerel anahtar `ritimFlowLite:fictional-demo:v1`; P0-07 backup/recovery kopyaları aynı namespace altında benzersiz `:copy:` anahtarlarındadır. İlk açılışta `demo.initialize` komutu P0-08 exclusive Web Locks ve kalıcı idempotency makbuzu ile kurgusal snapshot'ı yazar. Eşzamanlı ikinci ilk açılış aynı makbuzu kullanır; kilit yokluğu, kota ve erişim arızasında başlatma başarısız kalır, tekrar düğmesi bulunur. Kullanıcı komutları başarılı kurulum öncesinde kapalıdır. Mevcut yeni key bozuksa P0-07 recovery/export açılır. Eskiden kalan `ritimLiteAnonymousDemoV1`, onun `:copy:` kopyaları ve `ritimFlowLiteDemo` otomatik okunup içe aktarılmaz veya silinmez. Bağımsız satış sayfası `ritimFlowLiteDemo` için salt okunur ham arşivdir. Önceden kullanılan ama etkin olmayan `ritim-flow-lite-v4` okuması kaldırıldı. Oturum idempotency cache'i `KEY` ile bağlanır. Mevcut elle yedek kurtarma akışı korunmuştur.

Yeni anahtar, incelenen eski sabit-key yazıcısının olağan `setItem` çağrısını ayırır. localStorage bir yetkilendirme sınırı değildir: keyfî aynı-origin script yeni key'i yazabilir/silebilir veya `clear()` çağırabilir. Bilinmeyen eski istemciler, eski önbellekler ve mevcut gerçek Pages kodu ayrıca doğrulanmalıdır; hiçbiri bu testle güvence altına alınmaz. Eski ve yeni veri geçmişleri bağımsızdır; otomatik birleştirme ve migration yoktur. Eski kayıtlar başka adreste/release'de korunur; geri dönüş sırasında her iki key ve snapshot ayrı yedeklenmeli, eski kodun yeni key'e bakacağı varsayılmamalıdır.

## Tekrar çalıştırılan kontroller

- `npm run test:isolation` ve `npm run test:isolation:rc1`: her hedef için beş ilk açılış/kota/kilit/recovery/export/iki sekme ve iki eski-yeni birliktelik/idempotency kontrolü. Gerçek yerel eski commit `a28d5621f175f2e3f5f101396807d9eba60c4ff7` kodu geçici dizine çıkarılır; aynı origin'de iki gerçek tarayıcı sekmesi kullanılır. Yeni sipariş arayüzden açılır; tamamlanmış üretim test fixture'ı korumalı işlemle eklenir ve yeni sevkiyat yapılır. Eski sayfa gerçek `saveShipment()` kullanır. Önceki geçmiş korunur, yeni key byte'ları değişmez ve reload doğrulanır. Bu test üretim işlemlerinin tamamını UI'dan yürütmez ve yerel commit'in canlı Pages sürümü olduğunu kanıtlamaz.
- `npm ci` başarılı. `npm run test:ci` ilk koşusunda 292/292 alan, 12/12 paketleme/karakterizasyon, 1/1 smoke ve kaynak + artifact için ayrı ayrı 110/110 browser regresyonu geçti; her suite uygulama hatası 0 bildirdi. Bu koşu başlatıldıktan sonra `test:ci` komutuna yeni izolasyon suite'leri eklendi; bu iki suite son haliyle kaynak ve artifact üzerinde ayrıca çalıştırıldı (ayrı ayrı 7/7). Birleşik yeni `test:ci` komutunun tamamı bu güncellemeden sonra tek koşu olarak henüz çalıştırılmadı. GitHub Actions koşusu tamamlanmadı.
- CI workflow tam geçmişi indirir; test fixture'ı eski commit'e ihtiyaç duyduğu için shallow checkout desteklenmez. `test:ci` kaynak ve artifact izolasyon testlerini zorunlu tutar. GitHub Actions bu branch için çalıştırılmadı.
